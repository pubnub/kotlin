PNSetDataSyncUserEventMessage

data class PNSetDataSyncUserEventMessage(val source: String, val version: String, val event: PNDataSyncSetEventType, val type: String, val className: String?, val classLevel: String?, val classVersion: Int?, val data: PNDataSyncUserData) : PNDataSyncEventMessage

A DataSync User create/update event (wire type:"user"). data is the full current snapshot.

Also fires for a custom subclass of the built-in User class — the backend reports type:"user" for the whole User inheritance chain.

event is CREATE or UPDATE.
